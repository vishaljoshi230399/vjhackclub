UPLOAD INSTRUCTIONS (Android or computer):
1. Download and extract VJHackClub_All_Improvements.zip.
2. Open the repository on GitHub and choose Add file > Upload files.
3. Upload/replace index.html, style.css, script.js, robots.txt, sitemap.xml, and the assets/ and projects/ folders. Do not upload the ZIP itself as a replacement for the website files.
4. Confirm that the paths look like this at repository root:
   index.html
   style.css
   script.js
   robots.txt
   sitemap.xml
   assets/favicon.svg
   projects/business-website-demo.html
   projects/seo-growth-demo.html
   projects/security-lab-demo.html
   projects/demo.css
5. Commit the changes to the branch currently used by GitHub Pages (usually main).
6. Wait for publishing, then open the live site and test on mobile and desktop.

SEO:
- After publishing, open Google Search Console, add/verify the exact site property, inspect the homepage URL and request indexing if available, then submit sitemap.xml. Sitemap submission helps discovery but does not guarantee indexing or ranking.
- Verify the live robots.txt and sitemap.xml after publishing.
