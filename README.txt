VJHackClub website starter
==========================

Files:
- index.html: website structure and content
- style.css: responsive dark/aqua styling
- script.js: mobile navigation and enquiry form

Preview:
Open index.html in a browser. Internet is needed for Google Fonts and the remote background photos.

Before publishing:
1. Business email and WhatsApp contact links are configured with the details provided.
2. Replace the sample portfolio cards with real work when available.
3. Review service descriptions, prices, and business details.
4. Use your own logo and licensed images if desired.
5. Test all links and the enquiry form on mobile and desktop.

Free hosting option:
GitHub Pages can host a static HTML/CSS/JS website. Create a repository, upload these three files (and this README if desired), then enable Pages in repository settings. No hosting setup has been performed by this file creation.
